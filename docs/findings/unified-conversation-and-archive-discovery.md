# Unified conversation and automatic archive discovery

Status: first-target Stage 7.4.2 prototype, verified offline; live model-directed search pending.

## Reusable pattern
A manually scoped read-only investigation is useful to establish safe native tool transport, but manual record selection limits the value of intelligent discovery. Offer automatic local discovery as an independently selectable capability; preserve a narrower explicit-scope path. Distinguish capture, discovery, retrieval, transmission and execution permissions. Use clear consent for the broader scope, including later retained records, and require renewed consent when access is revoked and re-enabled. Do not silently upgrade an existing user's saved permission. An ordinary question can complete without any retrieval calls; no background activity.

At question preparation, freeze the eligible record identities and checksums. Recheck the scope after review; retrieve only authorized record versions. Return a bounded, filtered metadata page through a tool rather than transmitting the entire index. Use explicit units, axis identity, date semantics, pagination and unavailable-record counts. Search matches do not establish physical results. A range overlap does not guarantee a solved coordinate or even a successful root. Derive numerical evidence through the existing validated retrieval adapters. Avoid inventing negative findings when search is incomplete or capped. Keep index storage separate from scientific payloads and remove stale index entries when payloads change or are deleted. Bound legacy-record decompression work; preserve older records without destructive migration.

Conversation continuity requires provenance and revocation safeguards: include an archive-scope fingerprint in local snapshot identity and exclude old answers when permissions, relevant context or record versions change. Previous model answers are untrusted context, not numerical evidence. Conservative invalidation is acceptable initially; optimize only with evidence of a need. Do not replay revoked data through another context source. Local transcript and diagnostic retention are distinct from provider context. A review of the initial request cannot preview future model-selected tool results; explain and approve the bounded retrieval scope separately.

## Prototype evidence and limitations
First target exposes six native read-only tools, adding structured local archive search by result kind, mode, sweep axis, frequency range, one-based layer position, outer-radius range and creation date. Search and ordinary live snapshot are unified; automatic access defaults off, manual selected-record mode remains separately approved. Up to 2,000 eligible retained records in the frozen scope; max 20 matches/page and eight unindexed legacy records inspected per call. No archive metadata in initial message. Separate SQLite index table preserves the existing payload table, with checksum join and invalidation triggers. Scope changes exclude previous archive-derived answers. Existing six-call/seven-request and wire/time budgets remain; ordinary no-tool path remains available. No internet, execution, or arbitrary file access. Archive data and implementation stay target-local.

116 AI unit tests and 21 focused Tk GUI tests passed, including mocked native automatic retrieval and no initial archive ID transmission, follow-up context, revocation, changed-scope rejection, old-schema compatibility, search filters, legacy scan bounds, scope larger than manual limit, existing manual investigations and actual numerical capture/cache reuse. Existing numerical code unchanged. Existing NumPy matrix deprecation warnings nonfatal. No live automatic DESY tool-selection verification yet, no Windows/full numerical regression or large legacy archive performance benchmark. Metadata indexing is not semantic search; direct layer-thickness/material filter not implemented. Legacy metadata is not persistently backfilled; searches can stop incomplete due to bounded calls. Snapshot history invalidation can omit useful past answers after unrelated archive changes. Combined live context plus retrieval may hit request size limits.

Next: live evaluation of tool choice, evidence quality and ordinary questions without tool use. Separately scoped public-information web search with citations remains planned. Avoid sharing internal research context with external search engines.
