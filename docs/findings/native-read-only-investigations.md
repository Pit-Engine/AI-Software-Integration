## Pattern
Separate tool availability, authorization and actual execution. An investigation can start with a user-approved bounded set of immutable result IDs/checksums. The model chooses which local tools to invoke, but application code validates names, argument schema and semantic limits, scope, record version and output size. Treat retrieved strings and provider responses as untrusted. Include explicit tool errors, actual axis units and originating configurations; do not interpret a missing point as a physical cutoff or numerical failure without evidence. Replay only required native protocol fields and correlate each result with its call ID; no arbitrary path, network or execution tool. Bound repeated/invalid calls, requests, serialized output and cumulative wire bytes. Budget exhaustion should be visible. Do not silently retry or switch provider.

Use activity messages driven by actual request and tool events, not inferred model thoughts or fabricated completion percentages. A worker thread and UI event queue permit normal operation while requests run. Cancellation is cooperative: check before and after blocking operations, prevent subsequent calls and discard late answers. A synchronous HTTP request cannot be recalled, and socket timeouts are not strict wall-clock deadlines. Distinguish cancellation from successful completion. Record event metadata in opt-in normal diagnostics, exact successful request bodies in separately opted-in detailed diagnostics; exclude headers and credentials, and disclose that answers may contain research data.

## Prototype and limitations
Local target overlay keeps ordinary question answering intact and adds a separate per-question archive selection and approval. No records selected by default; up to 20 approved IDs. No live configuration, attachments, conversation, fields, fits or web search in archive mode. No automatic transfer; even the archive index is retrieved through a tool. Five validated archive retrieval tools, six local calls, seven provider requests, 20 KiB tool output / 64 KiB aggregate local output, 128 KiB individual request / 512 KiB cumulative request bodies, 1 MiB per response, 90 s checkpoint budget and up to 30 s per socket operation. Native multi-call response replay tested with mock transport; changed records fail rather than silently substituting. No execution permissions or numerical algorithm changes. 107 unit tests, three new investigation GUI tests and 13 existing assistant/history GUI regressions passed. Live auto tool choice, model reliability, Windows, strict cancellation and full numerical regression remain unverified. No target source or research data copied into the central framework.

Next evaluate live retrieval, then separately scoped external public-information search with verifiable citations. Consider unified interaction and adaptive retrieval only after permission behavior and model performance are understood.
