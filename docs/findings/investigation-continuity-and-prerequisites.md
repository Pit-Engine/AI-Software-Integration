## Proposed reusable integration guidance
- Distinguish recording, read access and external transmission internally, but check prerequisites and communicate capability readiness when enabling an AI feature. Offer explicit opt-in to missing prerequisites, preserve access to existing data without capture, expose actual eligible count and storage errors; never silently authorize data transfer. Test empty, disabled, failed and populated states. Logs should distinguish readiness from model selection behavior.
- Separate conversation and ongoing investigation intent from current numerical evidence. Preserve bounded prior answers across ordinary application changes with originating snapshot identifiers and explicit historical labels. Treat them as untrusted, not current scientific evidence. Continue excluding prior context after permission/attachment revocation or changes/deletion of authorized records. New records alone need not invalidate earlier context. The first-target implementation conservatively tracks the whole approved scope, not per-answer evidence lineage.
- Allow exact retrieval of the enabled retained result even without persistent capture. Freeze its identity and data at request preparation, distinguish it from an archive record and current edited settings, preserve scope and size bounds. Request-local aliases are not stable historical IDs.
- Prefer deterministic point-aligned comparisons to model arithmetic from representative samples. Report axes, shared coordinates, origin identifiers, differing inputs, missing values and mismatch statistics. Do not interpolate implicitly or infer physical equivalence from matching labels. A domain-specific conjugacy statistic is an arithmetic diagnostic, not a diagnosis of coupling, tracking failure or numerical validity.
- Use difficult real workflow cases to improve curated domain knowledge, including cases where unusual outputs represent plausible physics rather than numerical failures. Check scientific prerequisites and distinguish literature-supported general possibilities from application-specific verified findings.
